# Credits

## Project assets

The sedan, jeep, racing car, showroom geometry, floor pattern, and cubemap environment are generated by the project code. No external car models or image textures are used.

## Third-party libraries

- [GLFW 3.5.1](https://github.com/glfw/glfw) — window creation and input; fetched by CMake; distributed under the GLFW license (zlib/libpng-style).
- [GLM 1.0.3](https://github.com/g-truc/glm) — vector and matrix mathematics; fetched by CMake; dual-licensed under The Happy Bunny License or the MIT License.
- [GLAD](https://github.com/Dav1dde/glad) — OpenGL function loader; source is included in `third_party/glad`. The loader uses the MIT License; bundled Khronos headers include their own license notices. See `third_party/glad/LICENSE`.
